# Logo do Laboratório Maker – IFG Câmpus Jataí

Repositório com os arquivos vetoriais da logomarca do **Laboratório Maker do IFG Câmpus Jataí** (@labmaker.jatai).

## Arquivos disponíveis

- `.svg` – arquivo vetorial escalável, indicado para uso digital, edição gráfica e impressão.
- `.dxf` – arquivo vetorial compatível com softwares CAD e aplicações de fabricação digital, incluindo corte a laser.

## Conteúdo do arquivo DXF

O arquivo `.dxf` contém a logomarca do @labmaker.jatai e um **QR Code que direciona para a página do Linktree do laboratório**, facilitando o acesso aos seus links e canais de comunicação.

## Aplicações

Os arquivos podem ser utilizados na produção de materiais de divulgação, identificação de equipamentos, sinalização, brindes e outros projetos gráficos ou de fabricação digital.

**Créditos:** Laboratório Maker do IFG Câmpus Jataí — @labmaker.jatai.
